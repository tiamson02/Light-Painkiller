# Проверка Light v0.2.1 — оригинальный Painkiller и модификации

Проверить на одной и той же сцене:

| Вариант | Настройка | Задача |
|---|---|---|
| A | без DLL | Эталонная графика и FPS |
| B | `UnlockLights=0`, `ExtraPassesPerMesh=0`, `TimerSizeFix=0` | Контроль с нулём хуков |
| C | `UnlockLights=1`, `ExtraPassesPerMesh=2`, `TimerSizeFix=0` | Проверка новых проходов |

Проверять факел, фактуру светового пятна фонарика, оружие, освещение пола и стен, исчезновение света при повороте камеры, FPS. Перезапускать игру между тестами.

Если B отличается от A, искать проблему в загрузке и перехватчиках. Если только C отличается — проблема в добавлении дополнительных проходов. Специальный свет может оставаться ограниченным четырьмя источниками даже в C: это преднамеренно.

Для диагностики `LogLights=1`, файл `Light.log`: `extraInDraw`, `unsafeSkipped`, `incompleteNative`, `stockOnly`. Эти счётчики не доказывают визуальную корректность и могут не увеличиваться, если процесс не доходит до внутренних light passes. Реальную исправность фонарика подтверждает только сравнение изображения с игрой без патча.


**Дополнительный обязательный тест:** физически убрать Light/dinput8 прокси и убедиться, что дефект исчезает без неё. См. `DIAG_TORCH.ru.md`.
